# Hugoer v1.2.1

This patch release improves GitHub Pages deployment when the signed-in GitHub account is a repository collaborator.

## Fixed

- Distinguish repository push permission from GitHub Pages administration permission.
- Check `permissions.admin` before calling the Pages management API.
- Avoid repeated `HTTP 404` responses when a collaborator can push code but cannot change Pages settings.
- Tell the user that the repository owner must select **Settings > Pages > Build and deployment > Source > GitHub Actions**.
- Use `PUT` when Pages already exists and `POST` only when creating a new Pages site.

## Notes

- Website files and the GitHub Actions workflow can still be pushed with collaborator write access.
- Changing the Pages build source requires repository administration permission.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
