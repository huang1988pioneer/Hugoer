# Hugoer v1.3.1

Hugoer v1.3.1 fixes a misleading failure status when connecting to a repository owned by another account.

## Bug Fixes

- **GitHub Pages 權限訊息修正**：當推送成功但目前登入帳號沒有 repository 的 admin 權限（無法自動啟用 GitHub Pages）時，底部狀態欄不再顯示「連結或部署失敗；請查看操作日誌」，改顯示「推送成功；請由 Repository 擁有者在 GitHub Pages 設定中選擇 GitHub Actions 來源」。操作日誌中的詳細說明文字維持不變。

## Technical Details

- `CommandResult` 新增 `IsPartialSuccess` 旗標，用於表示「主要操作（推送）成功，但有次要步驟需要手動完成」。
- `GitHubService.EnablePagesFromActionsAsync`：無 admin 權限情況改回傳 `ExitCode = 0, IsPartialSuccess = true`，而非 `ExitCode = -1`。
- `GitHubViewModel`：`ConnectExistingRepositoryAsync` 與 `CreateAndDeployAsync` 依 `IsPartialSuccess` 分三種情況顯示正確訊息。

## Verification

- 無 admin 權限情境：狀態欄顯示推送成功提示，操作日誌保留完整說明。
- 有 admin 權限情境：流程與訊息維持不變。
- Release build 編譯通過，0 警告，0 錯誤。
