# Hugoer v1.2.0

Hugoer v1.2.0 focuses on safe GitHub Pages publishing, richer content editing, and a more complete Hugo configuration workflow.

## Highlights

- Connect an existing GitHub repository by URL, detect user/organization Pages sites, and synchronize the recommended `baseURL`.
- Safely fetch and merge existing remote content before pushing. Hugoer stops on conflicts and never force-pushes.
- Check repository push permission before deployment and recover a missing `origin` remote from the configured repository URL.
- Add a Markdown rich editor with formatting tools, preview, front matter editing, and validation.
- Add a detailed configuration editor based on current Hugo documentation, including Stack theme settings.
- Add an **Open website** button for the local preview and wait until the Hugo server is actually ready before opening it.
- Repair malformed Hugo configuration where possible and migrate the legacy Stack search page layout.
- Improve Hugo Extended installation detection and Windows package installation behavior.

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer.
- `Hugoer-win-Portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.

## Notes

- The Windows artifacts are not code-signed. Windows SmartScreen may show an unknown publisher warning.
- GitHub deployment requires Git, GitHub CLI (`gh`), and an authenticated GitHub account with push access to the target repository.
- The release targets Windows x64 and requires no separate .NET installation.
