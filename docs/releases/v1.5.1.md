# Hugoer v1.5.1

Hugoer v1.5.1 improves Git repository workflow clarity and Markdown media preview.

## Highlights

- Record recently used repositories across GitHub, GitLab, Codeberg, and Bitbucket.
- Keep the local site folder, remote repository URL, and final Pages URL as separate values.
- Show recent repository entries with clearly labelled local, remote, and published URLs.
- Preview MP4/video, audio, and PDF content in the live Markdown preview.
- Convert supported Hugo media shortcodes and media links to previewable HTML while preserving the original Markdown.

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer, when available.
- `Hugoer-win-Portable.zip`: portable Windows x64 package, when available.
- `Hugoer.exe`: single-file Windows x64 executable.

## Verification

- Main application builds with zero warnings and zero errors.
- Markdown WYSIWYG harness passes, including video/audio/PDF preview assertions.
- Media asset harness passes.
- Front matter formats harness passes.

## Notes

- The live preview uses embedded media data when local files are available.
- PDF preview depends on the embedded browser's PDF support and also provides a fallback link.
- Original Markdown is not rewritten by preview conversion.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
