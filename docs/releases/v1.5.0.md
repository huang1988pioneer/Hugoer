# Hugoer v1.5.0

Hugoer v1.5.0 adds Hexo／Jekyll article export and site migration, and expands Git Pages deployment beyond GitHub.

## Highlights

- Export the current article or all articles as **Hexo** or **Jekyll** compatible YAML Markdown (`YYYY-MM-DD-slug.md` in `_posts`, drafts in `_drafts`).
- Add a **遷移** page for **Hexo／Jekyll → Hugo** and **Hugo → Hexo／Jekyll**. Posts, pages, static files, and a basic config file are converted; themes and plugins are not.
- Convert common Hugo shortcodes and Hexo／Jekyll tags into portable Markdown (images, fenced code, YouTube, `<!--more-->`).
- Parse YAML block lists, nested `cover.image`, and `|` description scalars so Hexo／Jekyll front matter imports cleanly.
- Deploy to **GitHub**, **GitLab**, **Codeberg**, and **Bitbucket** Pages from the Git 部署 page. Provider-specific access checks, workflow pinning, and protected-site monitoring are included.
- Expand Markdown authoring with additional CommonMark／GFM／Markdig syntax in source mode.

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer.
- `Hugoer-win-Portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.

## Verification

- Site migration harness: detect Hexo／Jekyll／Hugo, convert front matter and shortcodes, migrate both directions, export articles.
- Front matter formats harness: YAML lists, nested cover image, block scalars.
- Git provider selection, clone, and deployment monitor harnesses pass.
- Release build completes with zero warnings and zero errors.

## Notes

- Site migration writes a `hugoer-migration-report.txt` (or export report) in the destination folder. Review warnings for leftover shortcodes.
- Themes, layouts, and plugins cannot be converted. Reinstall a theme on the destination engine.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
- The release targets Windows x64 and requires no separate .NET installation.
