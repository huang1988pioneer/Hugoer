# Hugoer v1.8.0

Hugoer v1.8.0 is a desktop runtime refactor: the same publishing and editing
workflows, with less process probing, fewer config rewrites, and safer Git
argument passing. This is also the first GitHub Release after v1.5.2, so it
includes the unreleased v1.6.0 and v1.7.0 work.

## Highlights

- Cache a successful Hugo detection until the executable changes or an install
  invalidates it, so environment, build, and preview no longer re-scan PATH on
  every click.
- Repair `hugo.toml` in one read/write: drop duplicate root keys, migrate
  `languageCode` to `locale`, and lift the legacy Stack `colorScheme` scalar.
- Run independent `git` / `gh` status probes in parallel when loading Git
  deployment info.
- Pass Git, GitHub CLI, Hugo server, and theme clone arguments through
  `ProcessStartInfo.ArgumentList` instead of interpolated command strings.
- Derive the HTTP User-Agent from the assembly version so it no longer drifts
  from the packaged product version.
- Exclude mobile, installer, and artifact trees from the header source-line
  metric.

## Also in this GitHub Release (v1.6.0 – v1.7.0)

- Horizontal navigation, GitHub / GitLab / Codeberg / Bitbucket publishing,
  and safer file writes.
- `AppServices` composition root, shared `SiteSession`, remote-first GitHub
  Pages, and Windows ZIP / SHA-256 / manifest publishing.

## Windows downloads

- `Hugoer-win-Portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.

## Windows build

```powershell
.\scripts\publish.ps1 -Version 1.8.0 -Runtime win-x64 -SkipInstaller
```

The resulting executable is self-contained and does not require a separate
.NET installation. Velopack and Inno Setup are optional installer adapters.

## Verification

- Main application builds with zero warnings and zero errors.
- Source harnesses covering config repair, preview, settings, session, menu,
  migration, front matter, and Git helpers pass.

## Notes

- Windows artifacts are not code-signed, so Windows SmartScreen may show an
  unknown publisher warning.
- Git credentials remain in the operating system credential manager and are
  not written to Hugoer settings.
