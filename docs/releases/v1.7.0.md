# Hugoer v1.7.0

This release restructures the desktop runtime around an explicit composition
root and a shared site session, then hardens the Windows release pipeline.

## Highlights

- Page view models receive one consistent `AppServices` graph.
- Active-site path normalization, persistence and notifications live in the
  testable `SiteSession` module.
- Content preview accepts the active site as a bindable input, keeping media
  resolution aligned with the selected site.
- Content, menu and migration modules share one front-matter parser instance.
- Windows publishing now clears stale generated versions and emits a portable
  ZIP, `SHA256SUMS.txt` and `release-manifest.json` alongside the EXE.
- GitHub Pages is now the default publish route, following the repository-backed
  workflow used by Hugoer Mobile. The app pushes source files for remote
  Actions/Pages builds and exposes local `public/` generation only as an
  explicit or failed-remote fallback.

## Windows build

```powershell
.\scripts\publish.ps1 -Version 1.7.0 -Runtime win-x64 -SkipInstaller
```

The resulting executable is self-contained and does not require a separate
.NET installation. Velopack and Inno Setup are optional installer adapters.
