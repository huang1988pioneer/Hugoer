# Hugoer v1.4.0

Hugoer v1.4.0 separates article editing from site menus, and upgrades Markdown authoring with a WYSIWYG/source editor plus media uploads.

## Highlights

- Split the old mixed **內容** page into **文章** and **選單**.
- The article list only shows `mainSections` posts (typically `content/post`). Archives, search, and about are no longer treated as blog posts.
- Add a dedicated **選單** page for `menu.main` / `menu.social`: name, URL, icon, weight, and new-tab. Site pages (about, archives, search) stay on that page.
- Saving menus writes to `hugo.toml` (or a dedicated `menu.toml`) and removes `menu:` blocks from page front matter, so Home / Archives / Search no longer appear twice.
- New Stack sites no longer put menus in archives/search front matter; icons live on the config menu entries.
- Markdown editor supports **WYSIWYG** and **原始碼**, with a corresponding live preview.
- Upload images, audio, video, PDF, and other files into the site `static/` folders (for example `image/`, `music/`, `voice/`, `video/`, `pdf/`).

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer.
- `Hugoer-win-Portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.

## Verification

- Menu service harness: parse config and front matter, merge duplicates, strip page menus on save, classify articles vs pages.
- Front matter, WYSIWYG, and media asset harnesses pass.
- Release build completes with zero warnings and zero errors.

## Notes

- Existing sites that still have `menu:` in page front matter: open **選單**, save once, and Hugoer will move those entries into the config file.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
- The release targets Windows x64 and requires no separate .NET installation.
