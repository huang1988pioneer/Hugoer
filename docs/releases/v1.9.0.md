# Hugoer v1.9.0

Hugoer v1.9.0 ships the Quill writing surface, a quieter desktop chrome, and
a Hugoer icon. Windows portable ZIP remains the primary download. This
release also adds an Apple silicon disk image.

## Highlights

- Edit articles in Quill 2. WYSIWYG stays markdown-in and markdown-out, and
  source mode still keeps the full Markdown the converter already round-trips.
- Refresh the desktop workbench: one graphite palette, a tracked navigation
  group, and an editor bar that steps back so the page is the focus.
- Replace the Avalonia placeholder icon with a Hugoer mark: a paper page and
  a cyan ribbon on graphite.
- Build an unsigned macOS arm64 `.app` inside a `.dmg`.

## Downloads

- `Hugoer-1.9.0-win-x64-portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.
- `Hugoer-1.9.0-osx-arm64.dmg`: unsigned macOS Apple silicon app.

## Build

```powershell
.\scripts\publish.ps1 -Version 1.9.0 -Runtime win-x64 -SkipInstaller
```

```bash
./scripts/publish-mac.sh 1.9.0
```

The Windows executable is self-contained and does not require a separate
.NET installation. The Mac app is self-contained for osx-arm64.

## Verification

- Release build succeeds. One existing Avalonia warning remains: the command
  palette still uses the obsolete `Watermark` property.
- The macOS app process starts and stays running.
- The Windows ZIP tests clean. The DMG mounts and contains `Hugoer.app`.

## Notes

- Windows artifacts are not code-signed, so Windows SmartScreen may show an
  unknown publisher warning.
- The macOS app is not notarized. Open it from Finder with Control-click the
  first time.
- Git credentials remain in the operating system credential manager and are
  not written to Hugoer settings.
