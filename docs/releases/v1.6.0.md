# Hugoer v1.6.0

Hugoer v1.6.0 brings multi-provider Git publishing, safer content operations, and a top navigation layout to the Hugo workbench.

## Highlights

- Move the main navigation to a horizontal bar above the workspace; narrow windows can scroll the menu horizontally and each item keeps its description as a tooltip.
- Support GitHub, GitLab, Codeberg, and Bitbucket repository / Pages targets with independent account, repository, Pages URL, and commit settings.
- Generate provider-specific publishing guidance, including a pinned GitLab Pages workflow and Codeberg / Bitbucket setup notes.
- Harden Git, Hugo, content, menu, and settings operations with atomic writes, path traversal checks, cancellation / timeout reporting, and safer merge handling.
- Keep menu definitions separate from article Markdown and preserve Markdown, media preview, migration, and code-statistics workflows.

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer, when available.
- `Hugoer-win-Portable.zip`: portable Windows x64 package.
- `Hugoer.exe`: single-file Windows x64 executable.

## Verification

- Main application builds with zero warnings and zero errors.
- All 13 source harnesses pass, including provider selection, GitLab workflow, menu, process, settings, Markdown, media, migration, and deployment-monitor checks.
- The release executable starts successfully after the rebuild.

## Notes

- Git credentials remain in the operating system credential manager and are not written to Hugoer settings.
- GitLab, Codeberg, and Bitbucket Pages still require the platform-side settings described in the deployment panel.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown publisher warning.
