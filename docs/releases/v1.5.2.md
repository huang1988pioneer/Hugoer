# Hugoer v1.5.2

Hugoer v1.5.2 adds a visible source-code size metric to the main application panel.

## Highlights

- Show the application source-code count in the main window header.
- Display the number of non-empty lines and source files at a glance.
- Count C# and Avalonia XAML source files while excluding tests, documentation,
build output, distribution artifacts, and temporary files.
- Keep the metric generated from the actual project source directory at startup.

## Windows downloads

- `Hugoer-win-Setup.exe`: Velopack installer, when available.
- `Hugoer-win-Portable.zip`: portable Windows x64 package, when available.
- `Hugoer.exe`: single-file Windows x64 executable.

## Verification

- Main application builds with zero warnings and zero errors.
- The source-code statistics service is included in the Debug and Release builds.
- Existing Markdown, media, and front matter harnesses remain unchanged and passing.

## Notes

- The header metric reports non-empty source lines, not generated output or test code.
- If a packaged build cannot locate the source tree, the header reports that the metric
is temporarily unavailable rather than showing a guessed value.
- Windows artifacts are not code-signed, so Windows SmartScreen may show an unknown
publisher warning.
